# MultipleAI Solutions Website

**Empowering Businesses through AI**

A modern, professional website built with Next.js, React, TypeScript, and Bootstrap. Styled with a clean, corporate theme inspired by Flexa React template.

## Features

- ✨ Modern, responsive design
- 🎨 Professional Flexa-inspired theme
- ⚡ Built with Next.js 14 and React 18
- 📱 Fully responsive on all devices
- 🔒 TypeScript for type safety
- 🎯 Bootstrap 5 for styling
- 📄 Multiple pages (Home, About, Services, AI Agents, Projects, Resources, FAQ, Contact)
- 🖼️ Image assets from presentation

## Pages Included

1. **Home** - Hero section, services overview, how it works, why MultipleAI
2. **About Us** - Company mission, vision, team
3. **Services** - Detailed service offerings (5 main services)
4. **AI Agents** - Comprehensive AI agent catalogue (7 categories)
5. **Projects** - Featured work and client testimonials
6. **Resources** - Articles, videos, eBooks
7. **FAQ** - Frequently asked questions with accordion
8. **Contact** - Contact form with validation

## Getting Started

### Prerequisites

- Node.js 18 or higher
- npm or yarn

### Installation

1. Install dependencies:
```bash
npm install
```

2. Run the development server:
```bash
npm run dev
```

3. Open [http://localhost:3000](http://localhost:3000) in your browser

### Build for Production

```bash
npm run build
```

This will create a static export in the `out` directory.

### Deploy

The site is configured for static export and can be deployed to:
- Netlify
- Vercel
- GitHub Pages
- Any static hosting service
